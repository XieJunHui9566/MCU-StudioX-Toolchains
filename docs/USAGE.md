# 使用开发组件

正式目录地址：

`https://raw.githubusercontent.com/XieJunHui9566/MCU-StudioX-Toolchains/main/catalog/catalog.json`

目前目录包含已公开发布的 `stc.sdcc/1.0.1`，约 55 MiB。原有 11 个组件仍在补齐发布材料，不列为可下载状态。已有完整安装包继续使用其预装版本，本地组件仍可导出为 `.mcutoolchain`。

在支持开发组件的 MCU StudioX 中打开“工具 → 准备工程工具…”，输入上述地址并点击读取。它只寻找工程需要的明确 ID 和版本，不替换为最新版本。也可通过“工具 → 软件与组件分发…”读取目录，并选择可信发布者公钥。

现有 STC 器件包声明的 `stc.sdcc/1.0.0` 不会被 `1.0.1` 自动替代。新组件保留相同的 SDCC 编译器版本，但组件内容不同；工程必须明确切换组件版本或使用声明 `1.0.1` 的新器件包。

公钥位于 `trust/publisher.pem`，指纹见 `trust/publisher.json`。单独从下载站取得公钥不能建立信任；应与独立可信途径取得的指纹或后续 IDE 内置的可信指纹核对。当前 IDE 尚未内置本仓库入口和公钥，不会自动联网或自动信任。

也可从明确的已发布 Release 下载 `.mcutoolchain`，使用“工具 → 导入开发组件…”。导入前核对版本、编译器、归档摘要及来源；同身份不同内容拒绝覆盖。新版本并存，工程原锁定版本保持不变。损坏目录使用工具校验与修复。

完整与轻量安装包都能导入组件。组件不修改系统 PATH，不安装全局 Python，不自动连接或烧录设备。
