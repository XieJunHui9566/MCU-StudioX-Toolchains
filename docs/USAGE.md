# 使用开发组件

正式目录地址：

`https://raw.githubusercontent.com/XieJunHui9566/MCU-StudioX-Toolchains/main/catalog/catalog.json`

目前目录包含已公开发布的 `stc.sdcc/1.0.1`，约 55 MiB。原有 11 个组件及新增 ESP-IDF 5.5.5、6.0.3、6.1.0 仍在补齐发布材料，不列为可下载状态。已有完整安装包继续使用其预装版本，本地组件仍可导出为 `.mcutoolchain`。

当前 IDE 开发构建提供两个模式，完整包与轻量包共用入口：

1. “工具 → 准备工程工具…”中选择“自动从 GitHub 获取”，点击“获取并安装工程缺少的组件”。IDE 用内置地址和可信公钥自动读取签名目录、匹配、下载并安装明确版本，不需要粘贴地址或另选公钥。全部缺失版本已公开才开始获取，不能用最新版本代替。
2. 选择“手动导入本地组件”，点击“选择 .mcutoolchain 并导入…”，可一次选择多个缺失组件，核对身份和摘要预览后导入。此模式不访问网络。通用“工具 → 导入开发组件…”也可导入独立组件。

页面“取消操作”或顶部停止按钮可停止获取。已安装组件和有效下载片段保留，下次可以继续；已有组件被禁用或损坏时先启用或修复。工程源码、配置、版本和内容锁保持不变。工具菜单“从 GitHub 获取开发组件…”可直接浏览已发布版本。自定义来源、公钥和逐项下载预览位于“高级”区域。

现有 STC 器件包声明的 `stc.sdcc/1.0.0` 不会被 `1.0.1` 自动替代。新组件保留相同的 SDCC 编译器版本，但组件内容不同；工程必须明确切换组件版本或使用声明 `1.0.1` 的新器件包。

公钥位于 `trust/publisher.pem`，指纹见 `trust/publisher.json`。当前 IDE 开发构建已内置本仓库入口和可信公钥，可点击“已验证组件库”验签读取。旧安装版本是否具有该能力取决于实际构建；产品版本号本身不证明支持新功能。自定义来源的公钥仍须通过独立可信途径核对，单独从下载站取得公钥不能建立信任。打开 IDE 和检查工程不会自动联网。

也可从明确的已发布 Release 下载 `.mcutoolchain`，使用“工具 → 导入开发组件…”。导入前核对版本、编译器、归档摘要及来源；同身份不同内容拒绝覆盖。新版本并存，工程原锁定版本保持不变。损坏目录使用工具校验与修复。

完整与轻量安装包都能导入组件。组件不修改系统 PATH，不安装全局 Python，不自动连接或烧录设备。
